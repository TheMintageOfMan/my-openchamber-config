# my-openchamber-config

Private storage for my OpenChamber config, skills, template prompts, and related files.

I use this repo to keep a copy of my OpenChamber / OpenCode setup so I can track changes and reuse it.

## Layout

- `template-prompts/build.md` - copy of the current system prompt (`~/.config/opencode/agents/build.md`)
- `skills/openchamber-contribute/SKILL.md` - copy of the OpenChamber contribute skill (`~/.config/opencode/skills/openchamber-contribute/SKILL.md`)

More config, skills, and prompts may be added here over time.
